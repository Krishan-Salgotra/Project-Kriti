*"Every beautiful story begins with one unforgettable date."*

---

## 🌸 About The Project

Project Kriti is a handcrafted interactive web experience created as a special gift.

Instead of a traditional website, it takes the user on an emotional journey through beautiful animations, heartfelt messages, interactive memories, music, and surprises.

Every page is designed as a chapter of a story, making the experience feel more like a movie than a website.

---

## ✨ Features

- 🔐 Beautiful Login Screen
- 🌌 Premium Animated Background
- 🎵 Continuous Background Music Across Pages
- 🎬 Smooth Cinematic Page Transitions
- 📖 Interactive Timeline
- 🖼️ Memory Gallery with Modal Viewer
- ❤️ Automatic Heart Experience
- 💌 Love Letter Section
- 🎂 Interactive Birthday Surprise
- 💍 Promise Page
- ✨ Beautiful Glassmorphism UI
- 📱 Responsive Design
- ⭐ Optimized User Experience
